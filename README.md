# AnalisadorSintatico-Compiladores
Este repositório apresenta a implementação de um Analisador Sintático para uma versão simplificada do Pascal, servindo como parte da avaliação parcial da disciplina de Compiladores ministrada pelo professor José Carlos Martins Oliveira no VI Semestre 2026.2 do curso de Ciências da Computação da Universidade Estadual do Sudoeste da Bahia (UESB).
